# Movie Genre Codabench Bundle

This directory contains a Codabench v2 competition bundle for single-label movie genre classification from title and synopsis.

Before uploading:
- update `contact_email` in `competition.yaml`
- replace the template phase dates if needed
- optionally set a dedicated `queue` vhost in `competition.yaml`
- zip the contents of this directory for upload

The split boundaries are generated from `Final Annotate/ground_truth.json`.
